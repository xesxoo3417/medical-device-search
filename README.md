# 교수님 피드백 반영: 의료기기 품목 검색·평가

## 수정 내용
- 기존 TF-IDF 검색 유지
- Sentence-BERT(paraphrase-multilingual-MiniLM-L12-v2) 검색 선택 기능 추가
- 평가용 설명 30개와 Top-1 / Top-3 성능 측정 기능
- DB 외 가능성 입력 5개 별도 시험 기능
- 유사도 기준 미만 경고 표시 (단, 3개 후보는 참고용으로 표시)
- 기존 500개 CSV 열·데이터 그대로 유지

## 사용 방법
1. ZIP 압축을 풀고 GitHub 저장소 루트에 있는 `app.py`, `medical_devices_500.csv`, `requirements.txt`, `평가문항_30개.csv`, `DB외_시험문항_5개.csv`를 업로드/교체합니다.
2. Streamlit Community Cloud에서 재배포될 때까지 기다립니다. Sentence-BERT는 모델 최초 다운로드로 배포/실행이 느릴 수 있습니다.
3. `검색 성능 평가` 탭에서 TF-IDF를 선택해 평가한 뒤 Sentence-BERT를 선택해 같은 30문항으로 평가합니다.

## 해석 주의
- 30개 문항의 기대 품목은 연구용 가정으로 작성했으며 의료기기 규제 전문가 검증 전입니다.
- Top-1과 Top-3는 이 평가 문항에 대한 결과이지 실제 전체 의료기기 분류 정확도가 아닙니다.
- DB 외 5문항 역시 500개 목록에 정확한 품목이 없는지 공식 검증하지 않았습니다.
- 유사도 임계값은 예시값이며 DB 외 판정 기준으로 검증되지 않았습니다.
- 최종 의료기기 분류는 식약처 최신 고시와 전문가 확인이 필요합니다.
